DAA Python Practicals A1-A5

Files:
- Code_A1_Fibonacci.py
- Code_A2_Huffman_Coding.py
- Code_A3_Fractional_Knapsack.py
- Code_A4_01_Knapsack.py
- Code_A5_N_Queen.py

Run a program with Python 3, for example:
python Code_A1_Fibonacci.py

Validation notes:
A1: Iterative and naive recursive Fibonacci; counters count loop iterations and recursive calls.
A2: Greedy Huffman tree using a min-heap; supports one character and validates input.
A3: Fractional knapsack sorted by value/weight ratio; fractions are allowed.
A4: Bottom-up dynamic programming for 0/1 knapsack; items are not split.
A5: Backtracking with a fixed queen at the user-specified zero-based position. Unlike the original C++ code, it does not place another queen in the fixed row.

Complexities are printed by each program where applicable.
